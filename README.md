# 贵大 AI 小助手 (Guida AI Assistant)

基于 DeepSeek 大模型 + 本地知识库构建的 RAG 问答系统。

## 🚀 已完成的里程碑
- [x] **大模型 API 接入**：成功使用 Python SDK 调用 DeepSeek 官方 API，理解 Token 计费与请求机制。
- [x] **本地知识库构建**：完成长文本的读取、Chunking 切分与关键词检索。
- [x] **Web UI 开发**：使用 Streamlit 搭建前端界面，实现带打字机效果的流式输出。
